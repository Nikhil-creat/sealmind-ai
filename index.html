Built so a signed file can be trusted.

Cryptographic sealing

SHA-256 of the original and signed file, with the audit trail bound into PDF metadata via pdf-lib.

Append-only audit log

IP, device, token, timestamp and location captured for every signing event.

Encryption and limits

AES-256 at rest, TLS 1.3 in transit, 50 MB and 250 page caps, Redis rate limits and queued heavy jobs.

Compliance aligned

Designed around eIDAS, ESIGN and GDPR data minimization.

Questions.

Is this legally binding?

Signatures aligned with eIDAS and ESIGN are the goal, but this showcase is not legal advice. Have counsel review before relying on it.

Where do my API keys go?

Server keys live in Vercel environment variables. A key you paste in the chat stays in your browser tab and is sent only with your own requests.

Which AI runs the analysis?

Groq or Gemini, detected from the key and model-selected automatically, with fallback if one fails.

Are my documents stored?

The demo stores nothing. Text is sent to the AI provider only when you press analyze or ask Seal.
